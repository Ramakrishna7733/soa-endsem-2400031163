# Tourist Management - JWT Protected REST API

Base package: `com.klef.soa.endsem`

## Requirements
- Java 21
- Maven
- MySQL
- A pre-existing JWT signed using the same HMAC secret and algorithm configured in `security/JwtUtil.java`

## 1. Create database
Run in MySQL:

```sql
CREATE DATABASE tourism;
```

## 2. Configure database credentials
Edit `src/main/resources/application.properties` and set your MySQL username/password.

## 3. Configure JWT validation key
In `JwtUtil.java`, replace the demonstration key with the exact key used by the service that issued your existing JWT. This sample expects an HMAC-signed JWT (such as HS256). A token signed with a different key or algorithm will fail validation.

## 4. Run
From the project root:

```bash
mvn spring-boot:run
```

Or import as an Existing Maven Project in STS/Eclipse and run `TouristManagementApplication.java`.

## 5. Swagger UI
Open:

`http://localhost:8080/swagger-ui/index.html`

Use **Authorize** and provide your existing JWT. Then execute:

`POST /api/tourists`

Example JSON:

```json
{
  "name": "Rahul",
  "country": "India",
  "email": "rahul@gmail.com"
}
```

Expected successful status: `201 Created`.

Without a Bearer token or with an invalid token, the endpoint returns `401 Unauthorized`.

Optional read endpoint: `GET /api/tourists`.

## Notes
- The JWT is not generated by this project; it is only validated.
- `GET /api/tourists` is currently public. Only the POST insertion endpoint performs the requested token validation.
- The hard-coded key is for lab demonstration only. Do not use it in production.
